# The Visit – IB EALL Paper 2 guide

Revision guide for IB English A: Language and Literature, Paper 2 (comparative essay).

- PDF guide for printing.
- `index.html` – the same guide as a single web page, with the event bank, quote bank and issue arcs filterable by act and issue.

References take the form Two (40%): Act Two, about 40 per cent of the way through the act.
